## 검증 결과

### 코드 테스트

24개 테스트 통과. 수치 혼동, 본문 수치 오류, 중복·누락, 미등록 시스템, JSON 표시가 수치를 덮어쓰지 않는지, 최대 시도 후 보류, SSE의 초안 비노출을 확인했다.

### 동일 합성 답변 Before/After

23개 사례 중 오류·누락·형식 위반 17개에 대해 기존 검증은 1개, 개선 검증은 17개를 걸러냈다. 정확한 답변 6개 중 개선본은 5개를 통과시켰고, 자유형 답변 1개는 형식 때문에 보류했다. 자료와 규칙을 알고 만든 소규모 사례로 일반화 성능은 아니다.

### 실제 모델 자연 생성 통합 실행

로컬 `qwen3.5:2b`을 사용했다. 실제 MCP Tool·Resource·Prompt, LangGraph, 실제 모델의 경로를 실행했다. 6개 질문에서 6개가 지정된 검증을 통과했으며 오류 주입은 하지 않았다. 평균 전체 처리 시간은 9.47초, 평균 작성 횟수는 1.0회였다. 외부 유료 AI API를 호출하지 않았다.

### 의도적 오류 주입 재작성 확인 — 별도 실험

실제 모델의 첫 초안에서 CPU 값을 실험 코드로 한 번 바꾸었다. 검사기가 불일치를 발견했고 실제 모델이 피드백을 받아 다시 작성했다. 최종 `passed`, 작성 2회, 전체 16.942초였다. 이 결과는 자연 발생 오류율이나 실제 모델의 환각 감소율이 아니다.

### HTTP·화면 확인

실행 중인 로컬 서버의 POST 요청, 미등록 시스템 처리, SSE 초안 비노출 및 일반 대화 경로를 별도로 확인했다. 웹 화면은 실제 모델 실행 이름과 검증 통과/보류 결과를 보여준다.

## 구현 중 확인한 문제와 해결

소형 모델이 제목·구분 기호를 바꾸어 정확한 수치도 반려되는 문제가 있었다. 항목 이름을 JSON 스키마로 제한하고 표시 형식을 코드로 분리했다. 조사 대상 이름과 개수는 스키마로 제한하지만 수치는 원본으로 강제 치환하지 않고 검사한다.

처음에는 본문의 모든 퍼센트 표현을 금지했지만, 수치를 올바르게 반복 인용한 답변도 보류되어 본문 CPU·메모리를 시스템별 근거와 대조하도록 개선했다. 원문에 있는 명시적인 임계 조건은 현재 측정치와 구분한다. 개발 중의 실패 결과는 최종 통합 결과와 분리해 작업 기록에 보관했다.

## 한계와 내일 할 일

- 통과는 규칙 검증의 통과이며 원인·권장 조치 전체의 사실성을 보증하지 않는다.
- 자연어 검사에는 정규식을 사용하므로 모든 표현을 이해하지 못한다. 한글 수사나 간접 표현은 별도 개선이 필요하다.
- 실제 운영 수치가 아닌 샘플 모니터링을 사용했다. 소규모·단일 기기 실험이다.
- 재작성은 지연 시간을 늘린다. 검증 전 초안을 숨기므로 내용이 표시되기까지 기다려야 한다.
- 최종 결과 보고서와 발표 자료, Google 스프레드시트 결과 제출은 3일차에 진행한다.
- 내일은 새 기능을 늘리기보다 결과를 설명하고 시연하는 데 집중한다.

## 발표용 한 문단

기존 Base AI Agent의 형식 중심 검증을 시스템별 모니터링 근거 대조 방식으로 개선했다. AI가 작성한 상태와 CPU·메모리 수치를 비교하고, 오류가 있으면 구체적인 피드백으로 다시 작성하며, 계속 실패하면 검증 보류로 처리한다. 합성 사례 비교와 실제 로컬 모델 통합 실행을 구분해 확인했다. 다만 이 검증은 원인·조치 내용의 의미 전체를 보증하지 않는다.
